# autoware-documentation-cn

- [英文文档(原版)](https://autowarefoundation.github.io/autoware-documentation/main/home/)
- [中文文档(当前)](https://tomato-ros.github.io/autoware-documentation-cn/)

基于 [autoware-documentation](https://github.com/autowarefoundation/autoware-documentation) 进行翻译.


Autoware-documentation 中文文档项目是面向全球领先开源自动驾驶框架 Autoware 的中文本地化技术文档工程，旨在消除中文开发者的语言壁垒，让国内自动驾驶领域的研究者、工程师与爱好者能高效掌握 Autoware 的使用与开发方法。

本项目依托 Autoware 官方文档体系，对其核心内容进行精准、全面的中文化翻译与适配，涵盖 Autoware 的模块化架构、核心功能模块、部署流程、开发教程及实战案例等关键内容。

Autoware 作为基于 ROS/ROS2 构建的端到端自动驾驶开源软件栈，集成了感知、定位、规划、控制等全流程自动驾驶能力，被全球各个国家的开发者应用于无人车、物流配送、园区接驳、自动泊车等多场景，而本中文文档项目将同步跟进其技术迭代，还原官方文档的专业度与时效性。

我们坚持开源协作的理念，欢迎中文社区的开发者参与文档的翻译、校对、补充与优化工作，共同打造适配国内技术生态的 Autoware 中文知识体系。

无论是零基础的入门者，还是深耕自动驾驶的资深开发者，都能从这份中文文档中获取适配自身需求的技术内容，助力 Autoware 在中文社区的技术落地与创新应用，推动国内开源自动驾驶技术的发展与交流。

## 关于作者

公众号《番茄ROS机器人》作者，长期致力于 ROS2 与 Autoware 框架下的低速无人驾驶解决方案研发，专注技术实战与经验沉淀，分享低速无人系统开发中的技术难点、解决方案与行业思考，与开发者共同推动低速无人驾驶技术的落地与创新。
